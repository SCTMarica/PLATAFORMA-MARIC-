📊 Visão Geral do Sistema

A Plataforma Maricá é um portal institucional para a prefeitura com três papéis de usuário distintos, cada um com permissões e fluxos específicos.

👥 Fluxos por Tipo de Usuário

1️⃣ CLIENTE FINAL (Cidadão)
Acessa site publicamente (sem login)
HOME: vê banners, notícias destaque, eventos próximos
NOTÍCIAS: navega lista de notícias, filtra por data
EVENTOS: vê eventos, clica em "inscrição" (link externo)
MÍDIA: visualiza galeria de fotos, vídeos institucionais
SOBRE: informações sobre a prefeitura
CONTATO: formulário de contato / dados de atendimento
LINKS: links úteis e sociais
Se quer mais: REGISTRA/LOGA
PORTAL: acesso a setor específico (vacinas, inscrições, documentos)
2️⃣ SUPERVISOR/COORDENADOR (Gestor de Setor)
LOGA no sistema
PORTAL: dashboard do setor
Vê eventos/notícias do seu setor
Visualiza inscrições/participações
Exporta relatórios
ADMIN RESTRITO (provável)
Criar/editar notícias do seu setor
Criar/editar eventos do seu setor
Gerenciar mídias (fotos/vídeos)
Visualizar comentários/feedback
NÃO pode: gerenciar usuários, settings globais, outros setores
3️⃣ ADMINISTRADOR MASTER (TI/Gestor)
LOGA no sistema
ADMIN DJANGO (acesso total)
Users: criar, editar, deletar, atribuir papéis
Site Settings: cores, logo, contatos, taglines
News: CRUD completo
Events: CRUD completo
Media: CRUD completo
Social Links: CRUD completo
Logs de auditoria
PORTAL ADMIN: visão de tudo
Dashboard com estatísticas globais
Configuração do sistema: Django settings, permissões, backups

🚀 Funcionalidades Implementadas

  • ✅ Sistema de usuários com 3 papéis
  • ✅ Banco de dados com modelos de Notícia, Evento, Mídia
  • ✅ URLs e rotas do site público
  • ✅ Configurações globais do site
  • ✅ Templates base HTML
  • ✅ Containerização com Docker

🚨 Funcionalidades por Implementar

Prioridade Alta:

  • Autenticação Real: Login e registro com validação
  • Portal do Usuário: Views com funcionalidades distintas por papel
  • Inscrições em Eventos: Modelo para salvar inscrições no BD
  • Admin Restrito: Supervisores não devem acessar admin completo

Prioridade Média:

  • Sistema de permissões por setor
  • Dashboard/relatórios por setor
  • Formulário de contato funcional (enviar email)
  • Buscador de notícias/eventos

Prioridade Baixa:

  • Comentários em notícias/eventos
  • Sistema de notificações
  • Integração com redes sociais
  • Analytics/estatísticas

🔧 Stack Técnico

  • Backend: Django (Python)
  • Banco de Dados: PostgreSQL
  • Frontend: HTML5, CSS3, Bootstrap (provável)
  • Autenticação: Django Auth com modelo customizado
  • Containerização: Docker + Docker Compose
  • Idioma: Português (pt-br)
